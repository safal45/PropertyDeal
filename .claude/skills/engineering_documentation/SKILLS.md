# Engineering Documentation Skill

## Purpose

Maintain the long-term memory of the project.

Whenever important decisions are made:

- Architecture
- Database
- API
- Folder structure
- Roadmap
- Progress

update:

docs/architecture.md
docs/database.md
docs/roadmap.md
docs/decisions.md
docs/progress.md

## Rules

- Never overwrite useful information.
- Update existing docs.
- Preserve history.
- Do not modify application code.
- Summarize what changed.

## Output

Return:

- Files updated
- Decisions recorded
- Progress updated
